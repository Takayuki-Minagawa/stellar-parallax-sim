# 年周視差シミュレーター

地球の公転に伴う恒星の見かけの位置変化（年周視差）を、3D俯瞰・地球視点・グラフで体験できる教育用 Web アプリです。

> **対象**: 高校地学・宇宙分野の発展学習  
> **用途**: 授業補助・自習・天文距離単位「パーセク」の概念理解

---

## 機能概要

### 3 つの視点モード（ビュー上部のタブ / キー 1・2・3）

| モード | 説明 |
|--------|------|
| **俯瞰** | Three.js による 3D シーン。地球→恒星の視線を「背景の天球」まで延長し、当たる点が 1 年で描く楕円（＝見かけの動き）を教科書の図と同じ配置で表示。恒星での視差角 p の補助線、半年後の地球も表示できます。カメラは「斜め / 真上 / 真横」のプリセットあり。 |
| **地球視点** | Canvas 2D の星空。各恒星の「太陽から見た方向（＋）」を基準に見かけの位置を描画。**複数の恒星を同じ角度スケールで並べる**ので、近い星ほど大きく揺れることを比較できます。スケールバー付き。 |
| **恒星視点** | 選択中の恒星から望遠鏡で太陽系を見た図。地球が太陽の周りを描く小さな楕円と、その最大角距離 = 年周視差 p を表示します。 |

### タイムライン（ビュー直下）

- 再生 / 一時停止、1 か月送り・戻し、日付表示（「2月10日頃」）
- 公転位置スライダー（月の目盛りをクリックで移動）
- 速度 1×〜60×（1× = 1 年 / 60 秒）
- **どの視点モードでも再生できます**

### 操作パネル（左）

- **恒星タブ**: 実在の恒星 11 種を追加、自作恒星の追加・名前/色の編集・削除
  - 距離: 対数スライダー（1〜1000 pc）、数値入力、`÷2` / `×2` ボタン、単位切替（pc / 光年 / au）
  - **黄緯 β**（0° = 黄道上 → 直線、90° = 黄道の極 → 円）と **黄経 λ**（ずれが最大になる時期）
- **表示タブ**: 1 年間の軌跡・視差角 p の補助線・半年比較・年周光行差の ON/OFF、3D カメラのプリセット

### グラフパネル

| グラフ | 内容 |
|--------|------|
| **見かけの軌跡** | 黄経・黄緯方向のずれの x−y プロット。全恒星を同じスケールで重ね、選択中の恒星には月を表示。 |
| **時系列** | 黄経・黄緯方向のずれを 1 年分の波として表示。年周光行差（右軸）を重ねると 90° の位相差が分かります。**クリック・ドラッグで時刻を移動**。 |
| **視差と距離** | `p = 1/d` のカーブ（線形 / 両対数）。対数表示では地上望遠鏡・ヒッパルコス・ガイアの測定限界と測れる距離を表示。**クリックで選択中の恒星の距離を設定**。 |

### 学習パネル（右）

- **解説**: 選択中の恒星の 3 単位での距離、`p = 1 / d` の計算式、軌跡の形（黄緯による円・楕円・直線）、操作状態に応じた「いま起きていること」、しくみの解説カード（年周視差・パーセクとスケール感・軌跡の形と 2p・年周光行差との比較表・観測精度表・歴史・モデルの簡略化）、視差 → 距離の計算ツール
- **ミッション**: 12 個の観察ミッション。操作に応じて自動でチェックされ、達成すると「わかったこと」が表示されます（進捗はブラウザに保存）
- **測定チャレンジ**: 謎の恒星の見かけの軌跡のグラフから視差角を読み取り、距離を求める演習（初級 / 上級）。正解した恒星はシミュレーターに追加できます
- **クイズ**: 14 種類の問題からランダムに 6 問。数値は毎回変わり、選択肢もシャッフル。よくある誤解（半年のずれ = 2p など）も出題

### その他

- **初回ガイド / ヘルプ**（? ボタン）とキーボードショートカット: `Space` 再生、`← →` 1 か月移動、`1 2 3` 視点、`C` 半年比較、`A` 光行差、`T` 軌跡、`?` ヘルプ
- **URL 共有**: ヘッダーのリンクボタンで、言語・テーマ・視点・日付・表示設定・恒星（距離・黄緯・黄経）を含む URL をコピー。旧形式の URL も読み込めます
- **PWA 対応**: 「ホーム画面に追加」でオフラインでも利用可能（3D ビューは遅延読み込み）
- **日本語 / English**、**ライト / ダーク** テーマ（すべてのパネル・グラフが追従）
- PC は 3 カラム、スマートフォン・タブレットは「ビュー + タイムライン + 切替式パネル」のレイアウト

## 天文計算モデル

このアプリは**教育目的の簡略モデル**を採用しています。実際の観測・測量への利用は想定していません。

### 座標系

- 太陽を原点とする黄道座標系（xy 平面 = 黄道面、z = 黄道北極方向）。3D 表示では y 軸を上にとります
- 地球の公転軌道を半径 1 au の真円で近似
- 公転角度 θ（0° = 1 月 1 日頃）に対する地球の日心黄経: `L = θ + 100°`

### 見かけ方向の計算

1. 恒星を黄経 λ・黄緯 β の方向、距離 d [au] の位置に固定
2. 地球から恒星への単位ベクトルを求め、太陽から恒星への単位ベクトルとの差をとる
3. 差を恒星位置での天球面の東（黄経増加）・北（黄緯増加）方向に射影し、秒角に変換

結果は長半径 `p`、短半径 `p |sin β|` の楕円になります（黄道の極で円、黄道上で直線）。半年離れた 2 時点のずれは最大 `2p` で、地球が恒星の方向と直角の位置にあるとき（日心黄経 `L = λ ± 90°`）に起こります。

$$d \,[\mathrm{pc}] = \frac{1}{p \,[\mathrm{arcsec}]}$$

### 年周光行差

地球の公転速度方向 v̂ に向かって、光行差定数 κ ≈ 20.50″ だけ見かけの方向が傾きます。

$$\Delta = \kappa \, (\hat{v} - (\hat{v}\cdot\hat{u})\,\hat{u})$$

長半径 κ・短半径 κ|sin β| の楕円で、距離に依存せず、視差とは位相が 90°（3 か月）ずれます。

### 精度に関する注記

- 地球公転軌道を真円で近似（実際の離心率 ≈ 0.017）
- 恒星の固有運動・連星運動・大気差は考慮していません
- 3D 俯瞰図の距離（対数で圧縮）と角度は誇張して表示しています

## ローカル環境での実行

Node.js 18 以上が必要です。

```bash
# リポジトリのクローン
git clone https://github.com/Takayuki-Minagawa/stellar-parallax-sim.git
cd stellar-parallax-sim

# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで `http://localhost:5173/stellar-parallax-sim/` を開いてください。

```bash
# ユニットテスト
npm test

# 本番ビルド
npm run build

# ビルド結果のプレビュー
npm run preview
```

## GitHub Pages へのデプロイ

`main` ブランチへの push 時に GitHub Actions が自動的にビルド・デプロイします。

リポジトリを GitHub に作成した後、**Settings → Pages → Source** を `GitHub Actions` に設定してください。

デプロイ後の URL は `https://takayuki-minagawa.github.io/stellar-parallax-sim/` になります。
